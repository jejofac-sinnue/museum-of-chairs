# 의자 박물관 · Museum of Chairs

정적 사이트(index.html 하나)입니다. 빌드 설정이 필요 없습니다.

## Vercel 배포 (CLI)
    npm i -g vercel
    cd museum-of-chairs
    vercel          # 처음 한 번: 로그인 → 프로젝트 이름 museum-of-chairs → 나머지는 Enter
    vercel --prod   # 운영 주소(museum-of-chairs.vercel.app 형태) 발급

## 시간 고정 테스트
주소 끝에 #h=17.5 (17시 30분), #h=12, #h=22 처럼 붙이면 그 시각의 역광을 볼 수 있습니다.
